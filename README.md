## 🚀 Sobre

**Juggering** é uma solução móvel robusta desenvolvida, em um primeiro momento, para atender às necessidades da empresa **Vopec**. O objetivo principal é revolucionar a forma como equipes de engenharia gerenciam projetos e se comunicam.

O aplicativo atua como um hub central, permitindo que membros da equipe mantenham contato rápido e eficiente, além de oferecer uma visão clara sobre eventos corporativos e reuniões futuras. Com foco em performance e experiência do usuário, o Juggering oferece navegação fluida e suporte a altas taxas de atualização (120Hz).

---

## ✨ Funcionalidades

### 🛠️ Gestão & Produtividade
- **Gerenciamento de Projetos:** Acompanhamento de etapas e status de obras/projetos.
- **Agenda Corporativa:** Visualização prática de eventos da empresa e reuniões agendadas.
- **Comunicação Integrada:** Ferramentas para manter a equipe conectada em tempo real.

### 📱 Experiência do Usuário (UX/UI)
- **Suporte a 120Hz:** Animações e transições ultra-suaves para dispositivos compatíveis.
- **Navegação Fluida:** Arquitetura de rotas otimizada para agilidade no uso diário.
- **Customização:** O usuário pode ajustar aspectos do app para atender às suas preferências visuais.
- **Error Handling Robusto:** Tratamento de erros amigável que garante estabilidade e informa o usuário adequadamente.

## 🛠 Tecnologias

O projeto foi desenvolvido utilizando as tecnologias mais modernas do ecossistema mobile:

- **Frontend:** [Flutter](https://flutter.dev/) (Dart)

## 🔧 Instalação e Execução

Para rodar o projeto localmente, siga os passos abaixo:

### 1️⃣ Clonar o repositório
```bash
git clone https://github.com/kyokopp/juggering.git
```

### 2️⃣ Acessar a pasta do projeto
```bash
cd juggering
```

### 3️⃣ Instalar as dependências
```bash
flutter pub get
```

### 4️⃣ Configurar o Firebase
- Adicione o arquivo `google-services.json` na pasta:

```bash
android/app
```

### 5️⃣ Executar o app
```bash
flutter run
```
